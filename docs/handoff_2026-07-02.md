```text
patent_source_summary     即時計算同一專利來自哪些檔案與匯入時間
```

## 最新匯入規則

正式規則檔：

```text
docs\import_rules.md
```

核心規則：

```text
1. 匯入時主要只做分 table。
2. 欄位內容不混合、不改名、不跨欄位擇一覆蓋。
3. 多人/多公司不拆，原始內容同格保存。
4. IPC / CPC / FI / F-term / USPC 等分類碼不拆。
5. 授权公告号、未审查的公开号、申请号 放在 patents，資料庫欄位顯示為繁體，不混成 publication_number 或 application_number。
6. 公告日/公開日欄位原樣保留，不混成 publication_date。
7. 去重使用 授权公告号、未审查的公开号、申请号 三欄組合。
8. 三欄任一有值時，dedupe_key = WIPS_NUMBER_COMBINATION|授权公告号={授权公告号}|未审查的公开号={未审查的公开号}|申请号={申请号}。
9. 三欄都空白時，dedupe_key = WIPS_ROW|source_file_id|row_number。
10. dedupe_key 只用於去重，不代表資料欄位合併。
11. raw_records.raw_data 必須完整保留原始欄位與原始值。
12. patents 只放專利本身主欄位與 year 欄位。
13. patent_people 每筆專利寫入一列，人員來源欄位各自成欄，空欄位保留為 NULL。
14. 非 patents、非 patent_people 的 WIPS 欄位全部寫入 patent_attributes 寬表，空值也寫入 NULL。
15. 資料庫實體欄位顯示使用繁體中文或英文，不使用簡體中文。
16. 同一 dedupe_key 已存在時，patents / patent_people 依來源優先權更新，策略為 incoming_source_priority。
17. 既有值與新來源值不同時，以新來源值更新主資料，來源差異由 raw_records / patent_sources / patent_attributes 保留追溯。
18. 不同來源原始資料保留在 raw_records / patent_sources / patent_attributes 追溯。
19. 年份欄位保留為 integer，但前端/API 顯示時不要加千分位逗號。
```

重要理解：

```text
欄位保存：原始資料是什麼欄位，就按 mapping 放到對應資料表欄位；資料庫實體欄位使用繁體中文或英文。
去重：使用 授权公告号、未审查的公开号、申请号 三欄組合。
```

## 匯入模組狀態

主要檔案：

```text
backend\app\importers\wips_importer.py
backend\app\mappings\wips.py
backend\app\db\connection.py
```

目前支援 WIPS 來源格式：

```text

CSV
TXT
XML
MDB
```

備註：

```text
XLSX / CSV / TXT / XML 已做 dry-run 驗證。
MDB 需要本機安裝 pyodbc 與 Microsoft Access ODBC Driver，尚未實際測。
不同格式只影響讀取層，不改分表、保存與去重規則。
```

WIPS 欄位 mapping：

```text
backend\app\mappings\wips.py
```

已加入常見繁體欄名正規化，例如：

```text
國家代碼 -> 国家代码
資料庫名稱 -> 数据库名称
發明專利/實用新型 -> 发明专利/实用新型
標題 -> 标题
申請號 -> 申请号
申請日 -> 申请日
授權公告號 -> 授权公告号
主附圖 -> 主附图
文圖像文件(PDF)鏈結 -> 文图像文件(PDF)链接
```

注意：`raw_records.raw_data` 仍保留來源檔的原始欄名，不會被正規化覆蓋。
