## 目前欄位處理邏輯

### patents

一筆專利一列。

去重鍵：

```text
只看正式公告號：授权公告号
如果授权公告号 有值，dedupe_key = WIPS_OFFICIAL_PUBLICATION|授权公告号
如果授权公告号 空白，dedupe_key = WIPS_ROW|source_file_id|row_number
```

公告號 / 公開號：

```text
不選來源、不混成 publication_number。
原本是 授权公告号，就以 source_field = 授权公告号 保留。
原本是 未审查的公开号，就以 source_field = 未审查的公开号 保留。
原本是 审查的公告号，就以 source_field = 审查的公告号 保留。
去重只看 授权公告号，不看 未审查的公开号，也不看 审查的公告号。
```

公告日 / 公開日：

```text
不選來源、不混成 publication_date。
原本是哪個日期欄位，就用原欄位名保留到 patent_attributes。
```

申請日：

```text
申请日
```

另產生：

```text
application_year
publication_year
```

### patent_people

目前已改成不拆多人名/公司名。

形式：

```text
一件專利 + 一種角色 = 一列
多人/多公司保留在同一格
```

角色：

```text
applicant
inventor
agent
owner
assignee
assignor
declarant
```

### patent_classifications

分類欄位不再拆碼。

目前只做分 table：

```text
一件專利 + 一個分類來源欄位 = patent_classifications 一列
欄位值原樣放在 code
```

### patent_attributes

WIPS 其他欄位大多原樣存入。

公告號/公開號、公告日/公開日會保留原欄位。

目前原則：

```text
除了分 table，不做擇一、拆分或欄位混合。
唯一例外：去重只看正式公告號 授权公告号。
公告號欄位本身仍依原欄位名保留，不混成 publication_number。
```
