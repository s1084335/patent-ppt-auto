# Tasks: HTML 報表版面與章節改版

🔴 **貫穿全案的兩條紅線**：
1. 「相對應行動」**不得寫成每則必填**——那是第一世代模板化的直接成因。
2. 字級與尺寸的驗收一律量**渲染後的實際值**，不量原始碼裡寫了什麼。
   舊機制的教訓正是「SVG 寫 15.1」與「使用者看到 11.0」是兩件事。

⚠ 切片順序有依賴：A（字級解耦）必須先於 B（尺寸伸縮）——尺寸還綁著字級時，
改尺寸會連帶改字級，兩者都驗不準。
