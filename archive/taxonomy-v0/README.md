## 轉向的理由（2026-07-13 討論結論）

```text
① is-a 沒有任何來源會自動給
   聚類只給相似性（方向是後加的）；LLM 樹不保證嚴格 is-a；CPC 有大量主題分組；
   專家的分類混著 part-of / applied-to / 管理分組
   → 唯一能判斷包含【方向】的是共現的非對稱性 P(w_i|w_j)（分布包含假說）
   → 但這訊號要語料量 → 繞回「歸納式方法先天需要量」的原點

② is-a 不可替代的價值只有一項：推論
   「新概念是舊概念的特例」→ 自動繼承父節點性質
   其餘三項（導覽收斂、粒度控制、novel 偵測）—— 分群就夠，不需要 is-a

③ 粒度階層在小語料上可行，is-a 不可行
   TaxoGen 式遞迴：每個節點的子語料要【重訓 word2vec】→ 數百萬詞 → 525 筆必死
   BERTopic 式遞迴：用【預訓練嵌入】，嵌入不用重算，只需對子集【重跑 UMAP】
                    → 要的是「幾百個點」而非「數百萬詞」→ 19,696 條片語綽綽有餘
```
